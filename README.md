# 📊 HR Custom Data Analysis

## 📌 Project Overview
This project analyzes HR data using Microsoft Excel to uncover workforce insights and support strategic decision-making.

## 🎯 Objectives
- Analyze workforce distribution
- Evaluate employee performance
- Analyze salary trends
- Measure employee turnover
- Support HR strategic decisions

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## 📈 KPIs
- Total Employees
- Average Salary
- Turnover Rate
- Performance Rating
- Work Mode Distribution
